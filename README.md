# 📚 영어 내신 지문 문제 풀이 인터랙티브 웹앱 (English Reading Quiz App)

[![GitHub Pages](https://github.com/dyana/dyana.github.io/actions/workflows/deploy.yml/badge.svg)](https://[사용자명].github.io/[리포지토리명]/)

## 📌 소개 (Introduction)

이 프로젝트는 **고등학교 영어 독해 지문**을 활용한 내신형 문제 풀이를 위해 제작된 단순하고 인터랙티브한 웹 애플리케이션입니다.

사용자는 지문을 읽고 객관식 문제를 풀 수 있으며, 선택 즉시 정답 여부와 상세 해설을 확인할 수 있습니다. 별도의 데이터베이스나 서버 없이 **단일 $\text{HTML}$ 파일**로 작동하도록 설계되어 $\text{GitHub Pages}$를 통해 쉽게 배포하고 학습 자료로 활용할 수 있습니다.

**주요 특징:**

* **즉각적인 피드백:** 선택 즉시 정답/오답 및 해설 제공
* **내신 유형 반영:** 요지, 빈칸, 문법, 어휘, 문장 삽입 등 다양한 유형 포함
* **간편한 배포:** $\text{HTML}$, $\text{CSS}$, $\text{JavaScript}$ 단일 파일 구성
* **직관적인 학습 환경:** 지문 내 밑줄 및 문장 번호 표시 (내신 스타일)

---

## 🛠️ 설치 및 배포 방법 (Installation & Deployment)

이 프로젝트는 $\text{GitHub Pages}$를 통한 배포를 강력히 권장합니다.

### 1. 리포지토리 설정

1.  이 코드를 복사하여 **`index.html`** 파일로 저장합니다.
2.  새로운 $\text{GitHub}$ 리포지토리를 생성합니다.
3.  생성한 `index.html` 파일을 리포지토리에 업로드합니다.

### 2. $\text{GitHub Pages}$ 활성화

1.  $\text{GitHub}$ 리포지토리의 **Settings** 탭으로 이동합니다.
2.  좌측 메뉴에서 **Pages**를 선택합니다.
3.  **Source**를 **Deploy from a branch**로 설정합니다.
4.  **Branch**를 **`main`** (또는 `master`)으로 설정하고, 폴더를 **`/ (root)`**로 지정한 후 저장합니다.
5.  몇 분 후, $\text{GitHub Pages}$가 제공하는 URL을 통해 웹앱에 접속할 수 있습니다.

## 💡 사용 방법 (How to Use)

1.  **지문 확인:** 상단 지문을 읽으며 문제 풀이의 배경을 이해합니다.
2.  **문제 선택:** 화면 하단의 문제 카드에서 5개의 선택지 중 하나를 클릭합니다.
3.  **피드백 확인:** 클릭과 동시에 정답 여부(✔/✘)와 상세 해설이 표시됩니다.
4.  **다음 단계:** **[다음 문제]** 버튼을 클릭하여 다음 문제로 넘어갑니다.
5.  **결과 확인:** 모든 문제 풀이가 완료되면, 총점과 함께 전체 정답표가 표시됩니다.

## ⚙️ 코드 수정 (Customization)

문제 내용이나 지문을 수정하려면 `index.html` 파일의 `<script>` 태그 내부에 있는 **`const questions = [...]`** 배열을 직접 편집하면 됩니다.

* **`title`:** 문제의 제목 또는 질문 내용을 수정합니다. (빈칸/밑줄 기호 포함 가능)
* **`answer`:** 정답 번호 (1~5)를 수정합니다.
* **`options`:** 5개의 선택지 내용을 수정합니다.
* **`explanation`:** 정답 해설 내용을 수정합니다.
